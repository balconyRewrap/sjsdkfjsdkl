# Описание разработки нейронной сети

В проекте была разработана собственная нейронная сеть для классификации тональности русскоязычных текстов. Модель не основана на дообучении готовой языковой модели, а обучается с нуля на подготовленном корпусе текстов. Основная задача сети: отнести входной текст к одному из трёх классов тональности: `negative`, `neutral`, `positive`.

В качестве архитектуры была выбрана компактная transformer-модель, реализованная на PyTorch. Она состоит из собственного словаря токенов, слоя токенных эмбеддингов, позиционных эмбеддингов, нескольких слоёв `TransformerEncoder`, нормализации, dropout и финального линейного классификатора. Для классификации используется специальный токен `<cls>`, который добавляется в начало каждого текста. После прохождения последовательности через transformer-encoder скрытое состояние этого токена передаётся в классификатор, который выдаёт вероятности трёх классов.

Перед обучением тексты проходят токенизацию: строка приводится к нижнему регистру, затем разбивается на слова, числа и знаки пунктуации регулярным выражением. На обучающей выборке строится собственный словарь: в него попадают наиболее частотные токены, а редкие и неизвестные слова заменяются токеном `<unk>`. Также используются служебные токены `<pad>` для выравнивания длины последовательностей и `<cls>` для классификации всего текста.

Для подготовки данных были реализованы отдельные функции загрузки и нормализации разных датасетов. Все исходные метки приводятся к единому формату: `negative`, `neutral`, `positive`. Тексты очищаются от лишних пробелов, пустые строки удаляются, дубликаты по тексту исключаются. После этого данные объединяются в общий датафрейм с колонками `text`, `label`, `source`.

В подготовленном файле `prepared/combined_sentiment.csv.gz` содержится 395 305 примеров. Распределение по классам:

- `negative`: 161 099
- `neutral`: 79 408
- `positive`: 154 798

В этот подготовленный набор вошли следующие источники:

- `RuSentiment` — русскоязычные посты с разметкой тональности;
- `RuReviews` — отзывы на товары с тремя классами тональности;
- `Kaggle Russian News` — новостные тексты с sentiment-разметкой;
- `RuTweetCorp` — русскоязычные твиты, размеченные как положительные и отрицательные;
- `SentiRuEval` — наборы отзывов и сообщений с оценкой тональности по сущностям и категориям;
- `Linis Crowd` — тексты с числовыми оценками, которые были преобразованы в три класса.

Также в проекте предусмотрена поддержка локальных наборов `rus_sen_dat` и `kin_set_dat`. В `rus_sen_dat` находится 210 989 записей с числовой разметкой, которая переводится в классы `neutral`, `positive`, `negative`. В `kin_set_dat` хранится 131 669 текстовых файлов, разложенных по папкам `neg`, `neu`, `pos`.

Обучение выполняется через `train_from_scratch.py`. Данные делятся на обучающую и валидационную части с сохранением пропорций классов. По умолчанию используется 10% данных для валидации. Для оптимизации применяется `AdamW`, функция потерь — `CrossEntropyLoss`, а для стабилизации обучения используется ограничение нормы градиента. Качество модели оценивается по `accuracy` и `macro F1`, потому что macro F1 лучше показывает качество на всех классах, включая менее представленный нейтральный класс.

Основные функции, использованные в реализации:

- `tokenize_text()` — токенизация русского текста;
- `build_vocab()` — построение собственного словаря по обучающим текстам;
- `encode_text()` — перевод текста в последовательность id токенов;
- `make_collate_fn()` — формирование батчей, padding и attention mask;
- `ScratchTransformerClassifier` — собственная transformer-модель;
- `evaluate()` — подсчёт loss, accuracy и macro F1;
- функции из `sentiment_data.py` — загрузка, очистка, объединение и нормализация датасетов.

После обучения сохраняются веса модели, словарь и конфигурация. Для проверки используется отдельный скрипт `test_from_scratch.py`, который загружает сохранённые артефакты, прогоняет текст через ту же токенизацию и выдаёт предсказанный класс вместе с вероятностями по всем трём меткам.
